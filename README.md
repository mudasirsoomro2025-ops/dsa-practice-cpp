# Data Structures and Algorithms Practice in C++

C++ practice programs for learning data structures and algorithms.

## Programs

- Array traversal
- Linear search
- Binary search
- Bubble sort
- Stack using an array
- Queue using an array

## Tools

Open the `.cpp` files in Dev-C++ or another C++ IDE.

Every program includes `iostream` and `using namespace std;` and has its own `main()` function.
